# Contributing

Thanks for your interest in improving Cube Lab.

1. Fork the repository and create a focused feature branch.
2. Keep changes compatible with current mobile and desktop browsers.
3. Test the app in a browser, including touch interactions when changing input behavior.
4. If you change the app shell or icons, update the README and bump `CACHE_NAME` in `sw.js` so existing clients receive the update.
5. Open a pull request describing the change and how you tested it.
